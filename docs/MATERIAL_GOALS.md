# 素材目标：达到库存后停止

想把某种兑换券攒到 50 个时，在「添加指令」中选择「素材目标扫荡」，打开「编辑目标」，选择素材、填写目标库存并保存。保存即参与后续规划；不会启动游戏或自行消费。

首版支持 **普通关卡的 61 种资源**：T2～T5 装备兑换券、基础装备和信用点。弗拉瑞、特别采购、困难记忆、合成与商店优化不在本轮执行范围。T5 和信用点的完整主线来源保留「待实机补验」标记；它们执行前仍须在当前游戏版本中读到精确库存、选中实际关卡并确认可扫。

## 按分类选素材

在「编辑目标 → 添加素材」中，先选「装备兑换券」「基础装备」或「通用资源」。兑换券可再选 T2～T5，默认每阶只显示 12 种；卡片同时显示游戏图标和完整名称，悬停可看放大图及待补验提示。

也可直接搜索名称、部位或阶级，如「T3 耳环」「项链」「信用点」。搜索覆盖全部素材，不受当前分类限制；清空搜索返回之前的分类。「项链」也能找到游戏名为「挂脖风扇」的基础装备。

点击卡片或按空格勾选，可跨分类一次添加多种素材；已添加的素材会标灰，不能重复加入。点击「添加 N 项」回到共享目标列表，填写各项目标库存，再保存。取消选择不会添加素材，也不会丢失原先未保存的数量。共享目标列表同样显示小图标。

## 一次设置，首扫与尾扫共享

可将日程排成「素材目标扫荡 → 一键领取 → 素材目标扫荡」。两条指令引用同一份目标；第二条会重新读取库存和资源，领奖获得的素材也会减少缺口。

- 目标是最终库存，不是额外刷取数量。达成一次后结束，后来消耗不会自动补货。
- 修改目标数量或点击「重新开启」会创建新目标版本；暂停、排序、调整优先级不清除达成记录。
- 「同步游戏数据」只读取目标相关库存和候选关卡，不确认扫荡。正在运行任务时不能另起同步。
- 未读到的库存显示待同步，不填零。手工纠正仅修正预览，有效 30 分钟，执行时仍刷新；不会据此永久标记达成。

## 查看与调整目标表

「查看目标表」显示关卡、关联素材、预计次数与体力、预计产出及自动/手动来源。保存目标后直接生效，不需要再确认应用。

选择素材后可指定来源、限制本轮最多次数，或者恢复自动。上限设为 0 表示本轮不主动刷这项目标；其他目标的共同掉落仍可能增加它的库存。调低次数后，规划器不会换一关偷偷补回次数。永久不想刷的关卡在「共享目标 → 排除来源」设置。

临时调整只属于这条指令的本轮执行：普通日常开始时消费这份调整；计划模式按游戏日保存。复制日程只复制指令和保留体力，不复制临时调整、库存、回执或完成进度。

普通模式在一轮开始时冻结目标与约束；计划模式首次启动当天时冻结。中断恢复继续使用原来的限制。已经冻结的目标表只读，全局目标修改用于后续轮次/日期。未来日期不预分配今天的体力，执行时再生成安排。

## 执行规则

规划器按目标优先级和单位体力对缺口的覆盖比例做简单贪心选择，兼顾共同掉落、稳定选关。仅用已确认可扫的关卡；执行前再次核对，不由最高通关进度推断所有前置关卡都已三星。

每批最多 5 次，临近目标缩为单次。每批后复读精确库存，预计产出不写入真实库存。公开概率与数量用于估算；区间数量以低端数量估算，不假定均匀分布，也不宣称实测掉率。仅知道来源时单次后核对。

按游戏实际允许次数和剩余体力执行，保留体力默认 0；不购买、不补充、不使用恢复道具。资源不足、没有可扫来源或库存读不到时保留目标，继续后续日常。普通扫荡的固定次数、MAX 和 `unfinished_tasks` 保持原义。

## 中断与待核对

确认消费前写入批次身份，看到结果后保存实际次数；复读库存后原子保存回执、已用额度和达成状态。同一回执只应用一次。

若确认后没有明确结果，普通和计划模式都阻止自动重放。在素材窗口点击「核对上批结果」：

- 确认未执行：允许后续重试。
- 已执行或次数不明：保留未知次数记录，结束这条指令的本轮额度，后续指令重新同步库存后再安排。

已看到扫荡结果的批次保留已确认次数；库存读取中断不会撤销次数或再次消费。跨日保留目标与回执，不累加昨天的预计次数。尾扫完成共享目标后，计划日汇总不再沿用首扫的素材余项。

## 数据与代码位置

- `src/material_catalog.json`：公开的普通关卡重复来源、版本和验证标记，不含账号资料。素材身份沿用公开资料引用；来源是固定版本 MAD-Viewer，游戏数据权利不随上游代码许可证转移。
- `core/material_store.py`：玩家目录下的 `material-goals.json`；原玩家配置 `state/<profile>/material-state.json` 中的观察、达成状态和回执。计划日临时配置不创建第二套素材进度。
- `core/material_planner.py`：纯规划，不操作设备。
- `module/material_sweep.py`：按需观察、复用选关及单批扫荡、复读库存。
- `gui/fragments/materials.py`：共享目标、预览、临时调整、结果核对。
- `gui/material_picker.py`：分类、阶级、全局搜索和批量选择；`src/material_catalog.json` 中的分类、部位、阶级和图标路径仅用于展示。
- `src/images/materials/`：61 张内置素材缩略图；来源版本和原始路径见 `provenance.json`，浏览时无需联网。

游戏版本不符只阻止素材指令，不给原有任务增加库存同步或目录版本前置条件。运行时不读取研发采集目录或旧账号快照。

## 手工验收顺序

先用普通日常单独启用素材指令，暂不启用计划自动执行。每项测试结束后再配置下一轮；已开始的计划日不能修改本轮目标。

1. 添加一个已持有、普通关卡可刷的 T2 兑换券目标，先点同步。确认名称、库存和可扫来源与游戏一致；同步不应出现消费确认。
2. 把目标设为低于当前库存，启动普通日常的这条素材指令。应跳过，体力不变。
3. 重新开启并设置小缺口，保留大部分体力，检查小批消费、复读库存、达标停止。
4. 再提高目标库存，并在新一轮开始前把本轮上限设为 1，确认未达标也不从其他关卡补回；再用独立尾扫处理余项。
5. 按「首扫 → 领奖 → 尾扫」验证共享需求；尾扫达标后，计划日不应还显示首扫的素材余项。
6. 中断后恢复，核对已确认批次不重复；未知结果先处理待核对提示。手工测试完成前保留自动计划关闭。
