# 当前工作状态

截至 2026-10-27，MADAutoScript 已完成独立项目、设备接入、领奖、日常、BAAS 流程整改和 Qt 工作台改版。当前 0.7.4 为本地发布候选，范围仅为 MAD ONEstore 中文版，未包含其他游戏助手。

## 已有实机验证

- MuMu 指定实例连接、ADB 截图和输入、中文/英文 OCR。
- 体力领取；普通多关扫荡；弗拉瑞、特别采购的学院交流形式选关与扫荡。
- 每关独立次数、部分完成后的剩余计划、资源不足正常结束、直接切换下一关。
- 指定角色的免费约会；邮箱、通行证、阿米商城、每日任务、积分箱与成就领取。
- 普通商店六种商品：0.7.2 验证购买后的实时重排，按 OCR 名称继续购买余项。
- Qt 界面的配置保存与重新打开、任务排序、三类关卡选单、停止和日志展示。

这些是此前在实际账号上的验证记录，不代表覆盖全部角色、所有关卡和每一种奖励状态。公开包不包含原始账号截图和运行记录。

## 尚未完成

- MAX 关卡完成后当前扫荡模块直接返回，列表后续关卡留待续跑；暂将 MAX 放在最后或使用明确次数。此限制由源码核对确认，本次发布未修改该流程。
- 竞技场与活动扫荡的实际功能。
- 特殊活动页面的领奖规则。
- 连续跨两次真实服务器日切的长期运行验收。
- Google Play 渠道、其他语言、其他模拟器与不同比例屏幕的验收。

## 维护边界

保留 BAAS 派生的任务组织和恢复方式，实际来源及许可证持续公开；游戏识别、页面入口和资源数据由 MAD 模块适配。后续新玩法按游戏需求维护，不要求逐项对应 BAAS。没有累计输入上限、累计消费上限或消费冻结账本。用户配置和 `unfinished_tasks` 独立于代码发布包，升级不重置已有进度。

2026-10-27 决定先发布当前执行框架并收集玩家反馈。MaaFramework 迁移暂缓，之前的设计仅作为历史资料，不是当前实施承诺；本次不引入 MaaFramework 或 MaaBd2/MXU 运行组件。

发布验证只检查本次安装与打包边界：干净目录启动、依赖、OCR、自包含测试、文件与配置隔离，不重复消耗游戏资源。

0.7.3 发布验证已完成：Windows 便携版从带中文与空格的新目录通过启动脚本打开；Qt 窗口和设备设置正常，34 个模板加载成功，内置 OCR 识别生成的中文与数字测试图。公开的七项针对性测试覆盖设备路径、计划顺序与进度保存、三类选单、商店重排以及工作台保存/停止/结果显示。

本轮未点击游戏、未消耗资源。真实完整日常流程沿用 0.7.2 及之前的实机证据；未在另一台物理电脑上验证便携版。

2026-10-27 补充发布隐私检查：清理导出关卡目录的本机证据路径，补齐 README 中的隐私说明；新增两项导出边界检查覆盖数据白名单、JSON/URI 路径、二进制字符串和分块边界。公开范围见 [README](../README.md#隐私与公开范围)。应用功能和依赖未改动，沿用上述启动及实机验证。

同日补充社区参与资料：贡献指南、Bug/建议模板、PR 模板、4 个新手待办及 README 入口。待办均为本地草案，尚未上传 GitHub；本次仅更新文档与发布清单，不改变功能和用户进度。

0.7.4 在上述基线上补充实际来源、完整依赖说明和缺失的许可文本。验证限于文档链接、许可证及源码对应、应用差异、归档完整性和隐私导出边界；应用功能与运行时未升级，复用 0.7.3 的启动、OCR 与之前的实机证据，不重复运行日常。实际检查结果随本地输出的发布验收记录提供。
