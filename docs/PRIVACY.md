## 排除和修复

此次检查发现关卡目录的两个证据字段包含本机绝对路径，原检查漏掉了 JSON 转义后的反斜杠。现已改为仅导出游戏数据字段；识别图的采集来源也仅保留内容哈希。工作目录的原始证据和个人配置保持原样，不进入发布包。

构建检查覆盖原始路径、JSON 转义、文件 URI、UTF-8 和 UTF-16LE 字符串，并扫描便携运行时。运行时复制还排除 `direct_url.json` 等本地安装来源及常见凭据文件。新增文件仍需人工复核，不能只依赖 `.gitignore` 或路径扫描。

已检查源码、便携版和第三方源码 ZIP 的文件清单与内容，包括第三方归档内部文件；搜索本机路径、常见访问令牌、私钥头和密码字面量，并人工核对匹配项与全部应用识别图。未发现发布者的账号配置、个人凭据或完整账号截图。

源码与便携 ZIP 内的应用源码保持一致；三个归档的校验值见同目录 `SHA256SUMS.txt`。此次仅修改发布文档、导出和检查逻辑，沿用此前便携启动、OCR 和任务功能的验收证据。

## 使用后哪些数据需要保密

`config/` 会保存设备安装路径、所选任务和剩余进度；`runs/` 与 `state/` 会产生运行记录、OCR 内容或截图，可能包含昵称、UID 和资源数量。反馈问题时只分享经过检查的必要片段。登录在游戏内完成，脚本不要求游戏密码；截图识别通过本机 OCR 服务进行。

发布新仓库请只上传 `source/MADAutoScript/`。不要上传已经使用过的便携目录、开发工作区或其 Git 历史；忽略规则不会删除已经提交的文件。保留上游作者归属与许可证中的公开署名信息。
