# 选择器缩略图

2026-11-19 · 未发布源码更新

## 在原来的选单中看图选择

- **指定角色约会**：当前角色和下拉选项显示头像；15 个地点显示场景缩略图，悬停查看完整横幅。地点优先顺序仍为 1、2、3，窄窗口自动换行。
- **普通扫荡、特别采购、弗拉瑞区域**：分类、待选列表和已选关卡表显示所属区域图。关卡名称和编号仍是区分同一区域关卡的依据。
- **普通商店**：六种商品的选择行显示对应图标，数量、单价与 MAX 语义不变。
- **素材扫荡**：保留原有素材图标，来源下拉框、永久排除列表和扫荡安排的关卡列补上区域图。
- **添加指令、一键领取、跟随指令**：使用 Fluent 功能图标区分操作。计划中的任务编辑器直接复用以上控件。

日期、时区、每日／每周周期、主题和用户自建模板仍使用文本；这些不是有游戏缩略图的对象。

本次只改变显示与布局，不迁移配置、不重建进度，也不连接模拟器。正常启动后，原有自动计划和日切行为仍然生效。

## 图片覆盖与一个待补项

内置 88 张原始 WebP：44 张角色头像、15 张地点图、6 张商品图、23 张区域／采购／弗拉瑞图；同一区域的关卡共用一张。来源固定为 [MAD-Viewer c312e4e](https://github.com/anyabot/MAD-Viewer/tree/c312e4e305cc57441e5bd615224642ea9b2168ce)，不在启动时下载。

原有 45 个角色选项中，**“零”未能与该版本的角色表可靠对应**。保留名称和选择值，使用中性占位并提示「头像待补」；未知的旧配置角色同样保留。确认其游戏内名称／角色编号后，再更新映射，不借用其他角色头像。

## 维护入口

- `src/selection_catalog.json`：展示映射、固定来源提交、上游路径与角色／地点／物品／区域编号。`characters` 和 `places` 的键保持现有中文选项；`shop` 保持商品 ID；`stages` 按区域或分类映射。
- `src/images/selections/`：随程序分发的图片。原图保持不变；地点图在 Qt 缩略图渲染中居中裁成 2:1，悬停用原图。
- `gui/selection_thumbnails.py`：本地图标、预览和原生列表装饰；不导入执行器，不读取玩家库存。
- `scripts/build_release.py::selection_assets()`：将目录清单、88 张原图和占位 SVG 共 90 个文件纳入源码包；便携包沿用该源码内容。

补图时先核对稳定编号与显示名，再加入原图及来源映射，运行 `tests.test_selection_thumbnails`。新增可执行角色或关卡属于 `core/game_catalog.py` 的独立适配，不能仅凭加图扩大支持范围。
